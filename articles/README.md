# Articles

Pre-prints, submitted versions, accepted manuscripts, and published versions of the journal articles that make up this article-based thesis. The integrative summary in `chapters/` should be considered the latest synthesis; individual articles in this folder are immutable snapshots tied to specific submission moments.

## Structure

Each article gets its own subfolder containing:

- `preprint.pdf` / `preprint.docx` — the version before peer review
- `submitted-{journal-shortname}.pdf` — the version submitted to a target journal (added when submission happens)
- `accepted-manuscript.pdf` — post-peer-review version (added on acceptance)
- `published.pdf` — typeset journal version (added on publication, where licence permits)
- `README.md` — article metadata: title, abstract, target journal, version history, status, key changes

## Stewardship

Article files in this folder are **canonical for that submission moment**. If chapter content in `chapters/` diverges from what's in a submitted article, the article is the source of truth for that scope; chapters/ may have evolved since submission and should note where they extend or refine the published artifact.
